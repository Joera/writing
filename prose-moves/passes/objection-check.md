# Objection check

## What it checks
*Which objections are unanswered?* Finds the questions an informed, sceptical reader would raise at each point, and whether the text answers them.

## When to run
After rewriting, section by section.

## How
1. For each section, write the two or three strongest objections a well-informed critic would raise. Write them as that critic would.
2. For each, find where the text answers it. Quote the answer.
3. If unanswered: is there an answer in the source that could be staged ([staged-objection](../section/staged-objection.md))? If not, is it a limit to state ([edges-statement](../section/edges-statement.md))? If neither, report it to the author.

## Output
Per section: objection · answered where · or "unanswered: suggest staged objection / edges statement / author to decide".

## Example
- §2 "Isn't this DRM?" → answered §2 ("access control on a public network, not rights management"). Could be staged.
- §6 "What stops the node operators colluding?" → not answered. Trust assumption to state once in §6.

## Source
Palmer's lens: what does each claim rest on, and which objections are unanswered.
